## OIBSIP - Data Analytics Internship

## About

This repository contains my projects completed during the **Oasis Infobyte Data Analytics Internship**.

The projects cover Exploratory Data Analysis, Data Cleaning, Customer Segmentation, Sentiment Analysis, Machine Learning, Fraud Detection, Google Play Store Analysis, and NLP-based Autocomplete and Autocorrect.

## Projects

### Level 1

#### Task 1 - EDA on Retail Sales Data
Exploratory Data Analysis of retail sales data to identify sales trends, customer behaviour, product performance, and business insights.

**Tools:** Python, Pandas, Matplotlib, Seaborn, Jupyter Notebook

#### Task 2 - Customer Segmentation Analysis
Customer segmentation using RFM analysis and K-Means clustering to understand purchasing behaviour.

**Tools:** Python, Pandas, NumPy, Scikit-learn, Matplotlib, Seaborn

#### Task 3 - Cleaning Data
Systematic cleaning and preparation of a deliberately messy dataset by handling missing values, duplicates, inconsistent data, and outliers.

**Tools:** Python, Pandas, NumPy, Jupyter Notebook

#### Task 4 - Sentiment Analysis
Sentiment analysis of Amazon Fine Food Reviews using Natural Language Processing and machine learning techniques.

**Tools:** Python, Pandas, NLTK, Scikit-learn, Matplotlib, Seaborn

### Level 2

#### Task 1 - Predicting House Prices
Prediction of house prices using Linear Regression and housing-related features.

**Tools:** Python, Pandas, NumPy, Scikit-learn, Matplotlib, Seaborn

#### Task 2 - Wine Quality Prediction
Exploratory analysis and machine learning on the Wine Quality dataset using physicochemical features.

**Tools:** Python, Pandas, NumPy, Scikit-learn, Matplotlib, Seaborn

#### Task 3 - Fraud Detection
Machine learning analysis for detecting fraudulent credit card transactions from an imbalanced dataset.

**Tools:** Python, Pandas, NumPy, Scikit-learn, Matplotlib, Seaborn

#### Task 4 - Google Play Store Analysis
Exploratory Data Analysis of Google Play Store applications, ratings, installations, pricing, categories, and user reviews.

**Tools:** Python, Pandas, NumPy, Matplotlib, Seaborn, Jupyter Notebook

#### Task 5 - Autocomplete and Autocorrect Data Analytics
NLP-based analysis and implementation of autocomplete and autocorrect approaches using text corpus data.

**Tools:** Python, Pandas, NLTK, PySpellChecker, Matplotlib, Collections
